# Asset provenance

All illustrations in `src/Art.tsx`, the creature drawings in `src/Toys.tsx`, CSS scene artwork, `public/icon.svg`, and the flower rasterization in `scripts/offline.mjs` were created for this application. They are covered by the repository's MIT license (see `LICENSE`). The paper texture is a local SVG filter embedded in CSS. No external image or font services are used.

Sound is generated by local oscillators in `src/audio.ts`; no third-party audio recordings are included. Interface text uses installed system fonts. Unicode symbols are rendered by the user's local system fonts.

React and React DOM are MIT licensed. Build and test tooling is installed through the committed npm lockfile; each package includes its own license. Build assets are bundled locally; no CDN is required.

## Font

`src/assets/fonts/andika-bold-latin.woff2` is Andika Bold (Latin subset) by SIL International, used for letters in Letter Friends because it is designed for beginning readers (single-storey "a"). It is licensed under the SIL Open Font License 1.1; the licence text is in `src/assets/fonts/Andika-OFL.txt`. The file is bundled into the build; no font is requested from the network at runtime.

Spoken words use the device's own speech synthesis voice; no recordings are included.
